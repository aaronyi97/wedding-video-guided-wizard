# 分镜、外部生图和图生视频

## 第 6 步

每镜记录 id、事实来源、对应旁白、成片区间、人物时期、地点、画风、首帧、核心动作、尾帧、衔接和返回检查点。时间来自已确认实际旁白，也包含情绪留白；源视频长度不等于最终使用长度。每镜一个叙事任务，允许简单辅助动作，少做多次手部交接、复杂旋转或多人调度。难事件用拆镜/换景别降低难度，不删改事实。

画风服从本单采集卡；动画区分真人脸＋动画环境和全动画人物。把参考风格转成光线、色彩、材质、景深等可执行要求，不依赖别的私有 Skill，不把所有订单固定为校园日系。共用画风并不意味着同一景别、同一光线。

人物身份来自本人照片。明确两人各对应哪张参考，合照清楚时可标注；容易混淆或不清晰时请补单人照，不能靠描述猜脸。确认年龄阶段、服装与重要道具。每个真人镜头都必须提供对应人物参考。

## 第 7–8 步：生图只能去外部 GPT

不调用 Codex 生图/编辑工具、不调用生图 API、不自动操作外部 GPT 的生成按钮。修图和人物母版同样由使用者外部完成。每镜给上传哪些参考图及顺序、完整提示词、画幅、返回文件名和检查点。默认 GPT 对话使用 GPT Image 2 或用户实际可用的相应能力，不能凭接口存在自动切换执行方式。

约三张试图根据本单风险和定调价值选择：双人身份、时期变化、关键情绪、手与道具；不能固定某三个剧情。短片不足三镜按实际数量。先说明每张试什么，确认后才输出其余词。

生图词描述一个稳定的瞬间：场景、光线、人物实际位置、手里已有物品、表情、构图、动作空间和保持要求。使用「第 1 张参考图是…」等清晰映射，不靠长篇五官替代图片。首帧避免不自然半扭转，不能把所有回头画面一律禁掉。

收到实际图逐镜检查：像本人、同一对人、时期、画风、手与物、乱码/多余人物、动作空间、相邻场景一致性。整套检查含旧试图，不能只收到余图就报全齐。选中版本及指纹登记，换图重查。

## 第 9 步

先看选中首帧，再列「实际起点→核心动作→结束状态」。已经抬头不倒退重演抬头，已经走近不重新从远处开始。首帧与关键情节冲突时，先提出局部修图/改分镜并确认，不指望视频词凭空修复。

每条视频词自含：明确来源图、时长画幅、连续动作和节奏、一个主要运镜、身份/服装/道具/场景保持项。一般一镜到底，无对白无配乐；有本单明确需要才例外。不重写外貌，位置可随动作改变，不同时要求走近与站位固定。

无论 API 还是手动，交付逐镜包：每镜一个目录，实际选中首帧图片＋视频提示词；根目录有使用说明和指纹清单。用 `wizard.py video-pack` 创建，禁止空壳路径包。模型需支持首帧，普通参考槽不自动等同首帧锁定。

手动说明：上传对应首帧→复制本镜视频词→设置时长画幅→生成→自查→按镜号发回。可以在本步建议先生成最难一镜减少浪费，不新增固定编号。有已配置可用且授权的视频 API 可当前对话执行。

返回后看完整动作与相邻剪点：核心情节是否成立、脸手物是否稳定、是否突然切镜或生成人声、动作有没有倒退。文案说到的关键动作没有发生时，局部重做或调整并重新确认；接受局部例外必须记录具体位置与制作方决定。解码通过不能替代观看，图片通过不能代替视频通过。
