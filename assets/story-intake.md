# 故事采集卡

给新人填，或由制作方对话式逐幕问。除加减项和音乐外全部必答，备注也必答。音乐只收不带歌词的纯音乐。

**怎么用**

- 问卷模式：整份发给新人自己填（网页版见 `story-intake.html`）。
- 对话模式：一次只问一幕，每幕不超过三问，上一幕答完再问下一幕。
- 每组选项都有"其他"，选了自己写。只选真实发生的经历；没有、记不清或不想呈现的，选"其他"说明，细节栏也可如实填写。
- 片子固定第三人称旁白讲述，不问旁白与字幕。
- 网页版填完点"复制故事卡"，通过微信等聊天方式发回制作方。不填写手机号，不向后台提交；照片原图通过聊天另发。电脑和手机都可填写，推荐电脑。
- 采集完整理成"故事卡"，让新人确认。有"未填"的项不出分镜。

---

## 第 0 部分 · 基本信息（全部必答）

1. 视频尺寸：[x] 宽屏 16:9（默认，现场大屏）　[ ] 窄屏 9:16（手机竖屏）　[ ] 其他 ______
2. 两人在视频里怎么称呼：新郎 ______ 　新娘 ______
3. 照片：通过聊天另发两人正脸合照或清晰单人照。也可补充大学或刚认识时的照片、婚纱照或试妆照；不在卡上上传。
   自拍是广角近距离，脸会比真人略宽，生成的画面会照着画；能再给一张别人拍的合照更好。
4. 在哪个环节播放：[ ] 仪式前暖场　[ ] 仪式中　[ ] 宴会开场　[ ] 其他 ______
   决定结尾旁白怎么落、配乐快慢。
5. 时长：[x] 90 秒（默认）　[ ] 180 秒　[ ] 其他 ______
   先选希望的片长；具体分镜由后续完整旁白的实际节奏决定。
6. 画风：[ ] 写实电影感　[ ] 水彩绘本　[ ] 纸艺折纸　[ ] 黏土定格　[ ] 可爱 3D 动画　[ ] 其他 ______
   选了写实电影感以外的画风再答一问——两个人怎么出现：[ ] 真人出镜，环境和画风是动画　[ ] 纯动画，两人也画成动画形象　[ ] 写实真人，不是动画（画风选"其他"且是写实时用）　[ ] 其他 ______
   这一项直接决定生图提示词怎么写：真人出镜保留照片里的脸和身材，只把环境和质感做成动画。

---

## 第一幕 · 相识（你们是怎么认识的）

7. 选一个：[ ] 校园同学　[ ] 同事　[ ] 朋友介绍　[ ] 网络认识　[ ] 旅行或活动偶遇　[ ] 青梅竹马　[ ] 其他 ______
8. 填一个：第一次见面在哪、什么季节、谁先注意到谁？______
9. 加一个（选填）：那天有没有一个你到现在还记得的小东西（一本书、一杯饮料、一句话）？______

## 第二幕 · 相知（是怎么慢慢走近的）

10. 选一个：[ ] 雨天共伞　[ ] 一起自习或加班　[ ] 一起吃饭　[ ] 深夜打电话　[ ] 一起旅行　[ ] 生病照顾　[ ] 一起做饭　[ ] 其他 ______
11. 填一个：对方做过的一件让你心动的小事。______

## 第三幕 · 确认（怎么在一起的，表白或求婚）

12. 选一个：[ ] 毕业时决定一起走　[ ] 表白　[ ] 求婚　[ ] 异地重逢　[ ] 决定同行（搬家、换城市）　[ ] 其他 ______
13. 填一个：在哪、谁开的口、说了什么？______

## 第四幕 · 相伴（一起生活的日子）

14. 选一个：[ ] 家中翻相册　[ ] 布置第一个家　[ ] 养宠物　[ ] 一起做饭　[ ] 异地坚持　[ ] 共同事业　[ ] 一起熬过一件难事　[ ] 其他 ______
15. 填一个：日常里最"你们"的一个画面。______

## 第五幕 · 承诺（婚礼当天，片子怎么收尾）

16. 婚礼在哪办（决定这一幕画在什么地方、什么光线）：[ ] 户外草坪或花园　[ ] 室内宴会厅　[ ] 中式庭院　[ ] 教堂　[ ] 海边　[ ] 旅行婚礼　[ ] 其他 ______
17. 结尾动作：[ ] 牵手走远　[ ] 回眸相笑　[ ] 拥抱　[ ] 交换戒指（只拍手，最稳）　[ ] 其他 ______
18. 填一个：想对对方说的一句话，会做结尾旁白。______

---

## 第 6 部分 · 加减项（选填，建议填）

这里的东西会直接变成画面里的道具、地点和旁白里的一句话，是片子最像"你们"的部分。

19. 想放进去的东西（可多选）：[ ] 宠物，名字 ______　[ ] 一个有意义的地方 ______　[ ] 一件有意义的物品 ______　[ ] 一首歌 ______　[ ] 一句你们常说的话 ______
20. 不想出现的东西：______
21. 五幕里有没有想换掉的一幕，换成什么：______

---

## 第 7 部分 · 音乐（选填，只收不带歌词的纯音乐）

22. 有没有想用的纯音乐：[ ] 我有想用的纯音乐：曲名 / 作者 / 链接 ______　[ ] 交给制作方定制
    带歌词的歌和旁白会打架，所以只收纯音乐。没有合适的，制作方用音乐模型（如 Suno）按片子情绪定制一首。

---

## 第 8 部分 · 备注（必答）

23. 注意点、参考、想法：想要的画面质感、参考的电影或照片、特别在意的地方、怕出错的地方，都写。______

---

## 整理成故事卡（制作方填，给新人确认）

```text
称呼：{新郎} / {新娘}　　尺寸：{}　　场合：{}　　时长：{}　　画风：{画风 · 真人出镜+动画环境 / 纯动画 / 写实真人}
照片：原图通过聊天另发，不包含在复制文字中
第一幕 相识：{选项} ｜ {填空} ｜ 加：{}
第二幕 相知：{选项} ｜ {填空}
第三幕 确认：{选项} ｜ {填空}
第四幕 相伴：{选项} ｜ {填空}
第五幕 承诺：{场地} ｜ {结尾动作} ｜ 结尾一句：{}
加项：{}　　禁忌：{}　　换幕：{}
音乐：{自带纯音乐「曲名」 / 制作方定制}
备注：{}
旁白：第三人称讲述（固定）
未填：{哪几项；无则写"无，可以写文案"}
```

有"未填"就退回去补，不出分镜。
