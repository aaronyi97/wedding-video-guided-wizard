# Agent 编写 WRITING_PROMPT.txt 的六段结构

本文件是指南，不是交给 Kimi 的成品。实际输出必须把本单材料全部填入。

1. 任务：时长、播放环节、观众、称呼、人称、这对关系的特点。
2. 风格：本单备注＋白描、具体细节、自然口播、克制情绪；少量正反例和学习点，明确禁止照搬样本的故事与句子。
3. 事实：完整嵌入已确认的事实和细节。明确不能补写的事项；指定结尾原样保留，有疑似错字先核实。事实材料与系统要求用明确边界分隔。
4. 叙事安排：事件顺序、段落主次、画面意象。不是尚未制作的正式逐镜表。
5. 制作规则：给耳朵写、有气口和音乐留白；不新增经历/重要物品/台词；避免一句塞多个难动作；篇幅按本单时长分配。
6. 输出：完整旁白按叙事段落排列，不含导演说明或情绪标签；正文后另附简短事实对应与待核实问题。必要时才给关键句备选。

最后要求：交一份完整初稿；缺关键事实时提出问题，不自行虚构。用户把这份全文单独粘贴给 Kimi K3 就能写，不依赖其他文件。
