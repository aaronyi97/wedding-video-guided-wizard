4在哪个环节播放
决定结尾旁白怎么落、配乐快慢：暖场留一步给仪式，仪式中直接落到誓言，宴会开场更轻快、可以带一句给来宾。
5时长
先选希望的片长，五幕按故事轻重分配；具体镜头根据后续旁白的实际节奏安排。
